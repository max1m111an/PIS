## Задание 1. Переменные и типы данных

В ходе выполнения задания изучены переменные и типы данных языка. Объявлены константа `firstName` (строка) и переменная `age` (число), для проверки типов использован оператор `typeof`, также объявлена переменная `isActive` типа `boolean`. Рассмотрено отличие `let` (переобъявляемая) от `const` (неизменяемая ссылка). Применена проверка поведения переменной без значения (даёт `undefined`) и переменной со значением `null`.

Применена функция `getType()`, которая определяет реальный тип значения: для массивов возвращает `"array"`, для `null` – `"null"`, для остальных – результат обычного `typeof`. Проверили результат выражения `typeof typeof 4`.

**Выводы:**
- `const` – неизменяемая ссылка, `let` – переменная, которую можно переопределить.
- Переменная без присваивания значения даёт `undefined`.
- `typeof null` возвращает `"object"` – историческая особенность, поэтому `null` распознаётся явной проверкой `value === null`.
- `typeof typeof 4` вычисляется «изнутри наружу»: `typeof 4` => `"number"`, затем `typeof "number"` => `"string"`.

На листинг 1 показано: объявление переменных, проверка типов `typeof`, функция `getType`, задача `typeof typeof`.

## Задание 4. Циклы

Изучены циклы языка. Для вывода чисел от 1 до 9 применён цикл `for`, для обратного вывода от 9 до 1 – цикл `while`. Для перебора элементов массива использован `for...of`, для перебора ключей объекта – `for...in`. Для обработки массива чисел применён `for`: подсчитана сумма элементов (переменная-аккумулятор) и количество чётных чисел (проверка `number % 2 === 0`).

Рассмотрена область видимости переменной, объявленной через `let` внутри цикла `for`. На рисунке 4.2 продемонстрирована ошибка при попытке доступа к переменной `i` за пределами цикла – `ReferenceError`.

**Выводы:**
- `for...in` перебирает только ключи объекта.
- Сумма элементов даёт `NaN`: в условии используется `i <= numbers.length`, поэтому читается несуществующий элемент `numbers[6]` (undefined), сложение с которым даёт `NaN`.
- Чётных чисел в массиве – 4.
- Переменная, объявленная через `let` в цикле `for`, недоступна за пределами цикла – внешний доступ вызывает ошибку.

На листинг 4 показано: циклы for, while, for...of, for...in, подсчёт суммы и чётных чисел.

## Задание 5. Область видимости (scope)

Изучена область видимости переменных. Объявлена глобальная переменная `appVersion`, доступ к которой выполнен из функции. Применено сравнение областей видимости: локальная переменная `area` внутри функции недоступна снаружи (см. рисунок 5.2), переменная `let` в блоке `if` не доступна за его пределами (см. рисунок 5.3), тогда как `var` «протекает» из блока наружу. Изучено создание локальной переменной внутри каждого вызова функции.

Рассмотрено явление теневой переменной (shadowing), когда внутренняя переменная перекрывает глобальную с тем же именем.

**Выводы:**
- `area` объявлена внутри функции и недоступна снаружи – попытка вывода вызовет ошибку.
- `blockVar` (let) недоступна снаружи блока `if`, а `var` «протекает» наружу, что противоречит блочной области видимости и считается плохой практикой.
- Каждый вызов `makeCounter()` создаёт новую локальную `count = 0`, поэтому результаты обоих вызовов одинаковые (0 и 0).
- При shadowing внутри функции `x = 20`, а глобальная `x` остаётся 10: вывод – 20, 10.

На листинг 5 показано: глобальная, функциональная и блочная область видимости, утечка var, makeCounter, shadowing.

Применена функция `makeGreeter`, фиксирующая имя через замыкание. Реализовано приватное состояние на примере банковского счёта `createBankAccount` с методами `deposit` и `getBalance`.

## Итоговое задание

Тема: учёт объектов категории «велосипед» в системе.

Для перебора массива и объектов использованы циклы `for...of` и `for...in` с выводом пар «поле – значение» в шаблонной строке. Через цикл посчитано среднее значение цены по всем объектам.

Использована функция-фабрика `createCatalog()`, которая через замыкание хранит счётчик операций и предоставляет метод для его получения. Продемонстрирована область видимости: переменная `specificScope` объявлена через `const` внутри функции и недоступна снаружи (см. рисунок 7.2).

- `specificScope` недоступен из глобальной области – внешний доступ вызывает ошибку, что подтверждает блочную область видимости.

На листинг 7 показано: массив велосипедов, вывод полей, средняя цена, фильтрация по порогу, фабрика-счётчик, область видимости.
